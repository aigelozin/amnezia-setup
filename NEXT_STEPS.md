# Продолжение работы

Состояние на 2026-10-01.

## Что сделано

- Сервер: Ubuntu 22.04, ядро 5.15.0-194, система обновлена и перезагружена.
- AmneziaWG установлен скриптом, интерфейс `awg0` поднят, автозапуск включён.
- UDP-порт VPN: **12869**. Клиент `client1` (10.8.0.2) добавлен.
- Ключи клиента сверены: публичный ключ, вычисленный из приватного, совпадает с пиром на сервере; хеш собранного `client1.conf` совпал с серверным.
- Клиент импортирован в Amnezia на телефоне.

## Где остановились

Телефон пишет «Подключено», но сайты не грузятся. В `awg show` у пира нет `endpoint` и `latest handshake`, `tcpdump -ni eth0 udp port 12869` пуст: **UDP-пакеты от телефона не доходят до сервера.**

Отдельно: SSH (TCP 22) с компьютера тоже не проходит, хотя сервер доступен из интернета (в логах есть чужие подключения), а iptables/ufw на сервере ничего не блокируют. Значит, режется где-то по пути.

## Что делать завтра (по порядку)

1. **Безопасность:** смени root-пароль на сервере, если ещё не сменил:

   ```bash
   passwd
   ```

2. **Firewall хостинга.** В панели хостинга найди Firewall / Security group. Если есть — добавь входящее правило UDP 12869 (источник 0.0.0.0/0). Проверь:

   ```bash
   tcpdump -ni eth0 udp port 12869
   ```

   Телефон на **мобильном интернете**, подключиться в Amnezia, подождать 10 секунд, Ctrl+C. Появились строки с IP телефона — пакеты доходят.

3. **Если пусто — перейти на порт 443:**

   ```bash
   sed -i 's/^ListenPort = .*/ListenPort = 443/' /etc/amnezia/amneziawg/awg0.conf && systemctl restart awg-quick@awg0 && awg show | grep port
   ```

   В Amnezia удали старое подключение и импортируй новый конфиг с `Endpoint = IP_СЕРВЕРА:443` (QR-код можно собрать на компьютере, см. README → «Известные проблемы»). Снова `tcpdump -ni eth0 udp port 443`.

4. **Когда пакеты дошли**, проверь `awg show`: должна быть строка `latest handshake`. Если пакеты есть, а handshake нет — сверить S1, S2, H1–H4 в приложении и на сервере.

5. **Если handshake есть, а сайтов нет:**

   ```bash
   sysctl net.ipv4.ip_forward          # должно быть 1
   iptables -t nat -S | grep MASQUERADE # должно быть -o eth0
   ```

6. **Доступ для Claude по SSH** (чтобы не работать через скриншоты): выяснить, почему компьютер не достаёт до сервера по TCP 22 — попробовать без VPN/прокси на компьютере или с другой сети.

7. **Потом:** вход только по SSH-ключу (`PasswordAuthentication no`), `apt install -y fail2ban`, отдельный клиент на каждое устройство.
