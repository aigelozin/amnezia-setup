# amnezia-setup

Скрипт ручной установки сервера **AmneziaWG** на Ubuntu одной командой, без приложения Amnezia и без Docker.

## Какую проблему решает

Обычно сервер Amnezia ставят из приложения на компьютере: приложение заходит на сервер по SSH и поднимает VPN в Docker. Это не работает, если SSH-соединение с твоего компьютера до сервера не устанавливается или рвётся (таймаут при установке). Например:

- провайдер или сеть режет соединения с зарубежным сервером;
- компьютер вообще не достаёт до сервера, хотя сам сервер в порядке.

Тогда VPN можно поставить **изнутри сервера**: через веб-консоль (VNC) в панели хостинга запустить этот скрипт. Он делает то же, что ручная установка из инструкции, только автоматически:

1. Включает репозитории исходников (`deb-src`), нужные для сборки модуля ядра через DKMS.
2. Ставит заголовки ядра и AmneziaWG из `ppa:amnezia/ppa`, загружает модуль `amneziawg`.
3. Включает пересылку трафика (`net.ipv4.ip_forward = 1`).
4. Генерирует ключи сервера и первого клиента.
5. Определяет сетевой интерфейс и настраивает NAT (MASQUERADE).
6. Выбирает случайный UDP-порт и **случайные параметры обфускации** (Jc, S1, S2, H1–H4) по правилам AmneziaWG.
7. Создаёт `awg0.conf` (сервер) и `client1.conf` (клиент), включает автозапуск `awg-quick@awg0`.
8. Открывает порт в ufw, если тот включён.
9. Печатает QR-код клиентского конфига для приложения Amnezia.

## Требования

- Ubuntu 22.04 или 24.04, доступ root.
- Свежая система: заголовки (`linux-headers`) должны быть доступны для **текущего** ядра. Если скрипт пишет «Нет заголовков для ядра», сначала:

  ```bash
  apt update && apt full-upgrade -y && reboot
  ```

  Во время обновления на вопрос про `sshd_config` выбирай **keep the local version currently installed**, иначе можно потерять вход по паролю.

## Установка

На сервере от root (через SSH или веб-консоль хостинга):

```bash
curl -fsSL https://raw.githubusercontent.com/aigelozin/amnezia-setup/main/awg-install.sh -o awg-install.sh
bash awg-install.sh
```

Необязательные переменные:

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `PORT` | случайный 10000–65000 | UDP-порт VPN. `PORT=443` помогает, если провайдер режет нестандартные UDP-порты |
| `ENDPOINT_IP` | определяется автоматически | Внешний IP сервера в клиентском конфиге |

```bash
PORT=443 bash awg-install.sh
```

Скрипт не запускается повторно, если `/etc/amnezia/amneziawg/awg0.conf` уже существует. Чтобы переустановить, сначала `systemctl disable --now awg-quick@awg0` и удали этот файл.

## После установки

1. Открой выведенный **UDP-порт** в панели хостинга (Firewall / Security group), если она есть.
2. Импортируй клиент в приложение Amnezia по QR-коду.
3. Подключись и проверь на сервере:

   ```bash
   awg show
   ```

   Строка `latest handshake: N seconds ago` у пира означает, что туннель работает. Надпись «Подключено» в приложении **ничего не гарантирует**: у WireGuard/AmneziaWG нет проверки соединения при подключении.

Файлы на сервере: `/etc/amnezia/amneziawg/` (`awg0.conf`, `client1.conf`, ключи). Приватные ключи (`*.key`, `client*.conf`) никому не пересылай.

## Известные проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| QR-код в веб-консоли из ромбиков `♦`, телефон не читает | VNC-консоль не рисует символы-полублоки | `qrencode -t ansi < /etc/amnezia/amneziawg/client1.conf`; если не влезает — вывести `cat client1.conf` и `sha256sum client1.conf`, собрать конфиг на компьютере и сверить хеш |
| Приложение «подключено», сайты не грузятся, в `awg show` нет `endpoint` | UDP-пакеты не доходят до сервера | `tcpdump -ni eth0 udp port ПОРТ` во время подключения. Пусто — открыть порт в панели хостинга или перейти на `PORT=443` |
| Скрипт молча останавливается после «Интерфейс: …» | Ошибка в ранней версии скрипта (исправлено в `13a299a`) | Скачать свежую версию |
| `sysctl: ... Invalid argument` на шаге 4 | Посторонние ключи в системных sysctl-файлах | Не влияет на VPN, игнорировать |

## Сменить порт уже установленного сервера

```bash
sed -i 's/^ListenPort = .*/ListenPort = 443/' /etc/amnezia/amneziawg/awg0.conf
systemctl restart awg-quick@awg0
awg show | grep port
```

В клиентском конфиге поменяй порт в `Endpoint` и заново импортируй его в приложение.
